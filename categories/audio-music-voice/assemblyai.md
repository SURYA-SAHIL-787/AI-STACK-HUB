## What it does

AssemblyAI is a hosted speech-to-text API competitive with OpenAI's Whisper API. It offers transcription, speaker labels ("diarization"), automatic chapter detection, sentiment analysis, content moderation, and a "LeMUR" feature for asking LLM questions about transcripts. Free signup credits let you transcribe several hours of audio before paying.

## Best use cases

- Building podcast/meeting apps that need transcription
- Adding voice features to your app
- Batch-transcribing existing audio archives
- Developers who want hosted infrastructure (vs running Whisper)

## Pricing breakdown

| Tier | Price | What you get |
|---|---|---|
| Free | $0 (signup credits) | Several hours of free transcription |
| Pay-as-you-go | $0.12/hour (Universal) or $0.37/hour (Slam-1) | Per-audio-hour pricing, no monthly minimum |
| Enterprise | Custom | Volume discounts, dedicated support |

## Beginner verdict

Not for end-users. Useful if you're a developer building features that need transcription. For personal transcription needs, use Otter or Descript instead.

- **Learning curve**: Moderate (API)
- **Setup required**: Free account + API key
- **Gotchas**: Pay-as-you-go billing — monitor usage on large jobs
