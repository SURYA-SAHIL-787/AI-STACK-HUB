## What it does

Recraft generates AI images with a designer-first toolkit — vector SVG export, brand style management, custom style training, mockup generation, and infinite canvas. Their proprietary model is strong on icons, logos, illustrations, and design assets (not just photorealism).

## Best use cases

- Icon and logo design
- Illustration in a consistent style
- Brand asset generation (multiple images sharing a look)
- Vector graphics that scale to any size

## Beginner verdict

If you're a designer (or learning design), Recraft's designer-first features beat general image gen tools. If you just want pretty pictures, Midjourney is more impressive out of the box.

- **Learning curve**: Moderate (more design-tool concepts to learn)
- **Setup required**: Free account
- **Gotchas**: Free tier doesn't grant commercial rights — pay if using for client work

## Alternatives

- [Midjourney](midjourney.md) — better photorealism, no vector
