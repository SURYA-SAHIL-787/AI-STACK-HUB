## What it does

Stable Diffusion is the most popular open-source text-to-image model. Anyone can download the weights and run them on a decent GPU. Many free web hosts let you try it without setup. Models include SD 1.5, SDXL, SD3, and the newer Flux family (which became dominant in 2024–2025).

## Best use cases

- Unlimited free image generation (if you have a GPU)
- Privacy-sensitive image work (runs locally)
- Custom-trained models for specific styles/characters
- Hobbyist art at scale without subscription costs

*Hardware: NVIDIA GPU strongly recommended for local use.*

## Beginner verdict

Easiest entry: use a free web host (Leonardo, Mage, Civitai) which run SD/Flux behind a friendly UI. Local install is rewarding but technical — not your first AI image tool.

- **Learning curve**: Easy (web UIs) / Steep (local install)
- **Setup required**: None for web UIs; GPU + Python for local
- **Gotchas**: Quality varies wildly by model and prompt; local setup can be a long rabbit hole

## Alternatives

- [Leonardo.ai](leonardo-ai.md) — friendly SD-based web UI
- [Midjourney](midjourney.md) — easier but paid
- [Playground AI](playground-ai.md) — another SD-based free host

## Notes

The "Flux" model family (released 2024 by Black Forest Labs, former Stability researchers) has largely supplanted Stable Diffusion 3 in the open-source community. Both run on the same tooling.
