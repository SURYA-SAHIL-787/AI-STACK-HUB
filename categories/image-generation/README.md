# Image Generation

AI tools that create images from text prompts (and sometimes from sketches or other images). Use cases range from concept art and design mockups to marketing visuals, illustrations, and stock-replacement.

---

## Quick comparison

| Need | Best pick |
|---|---|
| Photorealistic art | Midjourney |
| Free, no signup | Craiyon or Bing Image Creator |
| Commercial-safe (cleared for business use) | Adobe Firefly |
| Text inside images (logos, posters) | Ideogram |
| Designers — vector + raster, brand assets | Recraft |
| Open-source / self-hosted | Stable Diffusion |
| Quick experimentation with free credits | Leonardo.ai or Playground AI |
| Already paying for ChatGPT Plus | DALL-E 3 (included) |
