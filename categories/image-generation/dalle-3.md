## What it does

DALL-E 3 is OpenAI's text-to-image model, integrated into ChatGPT. Strengths: excellent prompt comprehension (you can describe complex scenes in plain English), conversational refinement (ask for tweaks in chat), text rendering inside images. Inside ChatGPT Plus, you can iterate naturally on each generation.

## Best use cases

- Conversational image work — "make it more colorful," "add a cat in the background"
- Quick visual brainstorming during ChatGPT use
- Generating images with text/typography embedded
- Already paying for ChatGPT Plus and want included image gen

## Beginner verdict

If you already have ChatGPT Plus, you have DALL-E 3 — no extra signup. If you want DALL-E 3 quality for free, use Bing Image Creator instead.

- **Learning curve**: Easy
- **Setup required**: ChatGPT Plus subscription
- **Gotchas**: Strict content filters; can refuse "harmless" prompts for safety

## Alternatives

- [Bing Image Creator](bing-image-creator.md) — same model, free
- [Midjourney](midjourney.md) — better aesthetic quality, no chat workflow
