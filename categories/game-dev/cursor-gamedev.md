## What it does

Cursor is a VS Code fork with AI deeply integrated — chat with the codebase, autocomplete, refactor. Strong for Unity (C#) and Godot (GDScript). Free tier covers most casual use.

## Best use cases

- Writing Unity C# behaviour scripts
- Refactoring Godot GDScript projects
- Reading unfamiliar engine source/plugins
- Generating shaders with AI help
