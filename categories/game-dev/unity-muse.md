## What it does

Unity Muse is Unity's in-editor AI assistant. Generate sprites and textures, ask questions about Unity APIs, generate animation rigs, and debug. Tightly integrated with Unity 6+.

## Best use cases

- Sprite/texture generation without leaving Unity
- Asking Unity-specific questions in context
- Auto-rigging characters
- Speeding up prototyping inside the engine

Right pick if your studio is committed to Unity. Skip if you're using Godot or Unreal.
