## What it does

Ludo.ai analyzes game market data — what's trending on app stores, what mechanics work in which genres, what design space is underserved. AI generates game concepts based on that data.

## Best use cases

- Picking your next indie game project
- Studio market research before greenlighting
- Generating hybrid-genre concepts
- Finding underserved niches

## Pricing breakdown

| Tier | Price | What you get |
|---|---|---|
| Pro | $15/mo | Personal use, ideation tools |
| Studio | $50/mo | Team access, market data |
| Enterprise | Custom | Full data access, API |

## Beginner verdict

Useful before you start a project. Skip if you already know what you're building.

## Alternatives

- [ChatGPT](chatgpt-gamedev.md) — generic but free
- SensorTower / data.ai — pure market data (no AI)
- Steam Charts — free competitive research
