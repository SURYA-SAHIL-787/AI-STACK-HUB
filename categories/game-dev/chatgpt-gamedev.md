## What it does

Not game-specific, but indie devs use it constantly: writing C#/GDScript snippets, debugging Unity errors, generating quest text, brainstorming mechanics, writing lore. Free tier is enough for most.

## Best use cases

- Writing Unity C# scripts from a description
- Debugging error messages you don't understand
- Generating dialogue and quest text
- Designing item names, lore, world details

## Pricing breakdown

| Tier | Price | What you get |

| Free | $0 | GPT-5 mini, basic features |

## Beginner verdict

Every indie dev should have this open. Free tier is enough.
