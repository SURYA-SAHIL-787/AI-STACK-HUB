## What it does

Windsurf is a standalone AI-first code editor (built on VS Code's open-source core) from the Codeium team. Its standout feature is "Cascade" — an agent that can edit multiple files, run terminal commands, and handle multi-step tasks autonomously while showing you each step.

## Best use cases

- Cursor-style workflow at a lower price ($15 vs $20/mo Pro)
- Multi-file refactors with agent supervision
- Developers already familiar with Codeium's products who want a full IDE experience

## Beginner verdict

Reasonable Cursor alternative — same VS Code base, similar AI features, lower price. If you're choosing between the two, try the free tier of each and see which UX clicks.

- **Learning curve**: Easy if coming from VS Code
- **Setup required**: Install desktop app + sign in
- **Gotchas**: Smaller community than Cursor — less tutorials/extensions specific to Windsurf

## Alternatives

- [Cursor](cursor.md) — direct competitor, more mature
- [Codeium](codeium.md) — same company, IDE plugin form factor instead
- [GitHub Copilot](github-copilot.md) — works inside VS Code without switching editors

## Notes

Built by the team behind [Codeium](codeium.md). Codeium = plugin you add to your IDE; Windsurf = full standalone IDE. Same AI tech under both.
