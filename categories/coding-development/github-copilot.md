## What it does

GitHub Copilot is the most widely used AI coding tool. It suggests code as you type, answers questions in chat, generates whole files from prompts, and (with Copilot Workspace / Agent) can take on multi-file tasks. Backed by OpenAI models with Anthropic Claude available on higher tiers.

## Best use cases

- General-purpose code completion across nearly any language
- Writing tests and documentation
- Refactoring with natural-language prompts
- Reviewing PRs (Copilot can leave automated review comments)

## Beginner verdict

If you're a student aiming at placements — apply for GitHub Education and get it free. It's the AI coding tool you'll most likely encounter in interview questions and at your first job.

- **Learning curve**: Easy
- **Setup required**: GitHub account + IDE extension
- **Gotchas**: Free tier limits reset monthly; suggestions can be wrong — always review
