## What it does

Cody is an AI assistant that uses Sourcegraph's code search engine to fetch relevant context from your entire codebase before answering. This makes it better than tools that only see open files — it can answer "how is `authenticate()` used across the repo?" with real evidence.

## Best use cases

- Onboarding to an unfamiliar large codebase
- Refactoring across many files
- Searching for usage patterns and code examples in your repo

## Beginner verdict

Not the first AI coding tool to grab. Shines when you have an existing large codebase — beginners working on small personal projects won't see the benefit over simpler tools.

- **Learning curve**: Moderate
- **Setup required**: Install extension + Sourcegraph account
- **Gotchas**: Full power needs your repo indexed in Sourcegraph
