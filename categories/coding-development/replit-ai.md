## What it does

Replit is a browser-based coding environment that includes AI features — completion, chat, debug help, and Replit Agent (autonomous app-building). You can write and run code in 50+ languages without installing anything.

## Best use cases

- Students learning to code without setting up a local environment
- Prototyping small apps quickly
- Coding from a Chromebook, iPad, or shared/locked-down computer
- Collaborative coding (Replit was multiplayer before Cursor was)

## Pricing breakdown

| Tier | Price | What you get |
|---|---|---|
| Starter | Free | Public repls, limited AI usage, basic compute |
| Replit Core | $20/mo | Private repls, more AI credits, faster compute, Agent access |
| Teams | $40/user/mo | Team workspaces, admin features |

## Beginner verdict

The single best place to learn coding if you don't want to install anything. Free tier is genuinely usable for learning. Replit Agent (autonomous app builder) is impressive but quickly hits paid limits.

- **Learning curve**: Easy
- **Setup required**: Just a browser
- **Gotchas**: Free tier compute is limited — heavy projects need Core

## Alternatives

- [Cursor](cursor.md) — desktop IDE, more powerful, paid
- [GitHub Copilot](github-copilot.md) — better if you already use VS Code locally
- [Codeium](codeium.md) — free completions for any local IDE

## Notes

Used heavily in CS education — many universities use Replit for intro courses. Replit Agent (their autonomous coding agent) competes with tools like Cursor's agent mode and Devin.
