## What it does

Tabnine provides AI code completion with a strong privacy stance — Enterprise plans support fully on-premise or air-gapped deployment so source code never leaves your network. The free Basic tier offers short, AI-powered completions.

## Best use cases

- Code completion in regulated industries (finance, healthcare, defense)
- Teams that can't send proprietary code to external AI services
- Developers wanting a Copilot alternative with privacy guarantees

## Beginner verdict

Solid free option if you care about privacy. Completions are shorter than Copilot's on the free tier — still useful but less impressive out of the box.

- **Learning curve**: Easy
- **Setup required**: Install extension + create account
- **Gotchas**: Free tier completions are intentionally limited — Pro is where it shines

## Alternatives

- [Codeium](codeium.md) — more generous free tier
- [GitHub Copilot](github-copilot.md) — more polished completions

## Notes

One of the oldest AI coding tools — predates Copilot. Recent versions added chat and agent features alongside their traditional autocomplete strength.
