## What it does

Cursor is a desktop code editor built on VS Code with AI woven into every workflow. Features include inline completion, chat with full codebase context, multi-file edits, an agent mode that can plan and execute tasks across files, and a "Composer" for larger refactors.

## Best use cases

- Building real applications faster — agent can scaffold, refactor, and debug
- Working on projects where you want AI to see and modify many files at once
- Migrating from VS Code without losing your extensions

## Beginner verdict

If you already know VS Code, switching to Cursor is friction-free — same UI, same extensions. The free Hobby tier lets you try the AI features. For serious use you'll want Pro.

- **Learning curve**: Easy if coming from VS Code
- **Setup required**: Install desktop app + sign in
- **Gotchas**: Pro's "500 fast requests/mo" can run out fast on agent-heavy work
