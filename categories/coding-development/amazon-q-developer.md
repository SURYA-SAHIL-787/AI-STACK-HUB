## What it does

Amazon Q Developer is AWS's AI coding assistant. It offers code completion, chat, and AWS-specific features — security scanning, AWS service guidance, code transformation (like Java 8 → Java 17 upgrade). The free tier is unusually generous compared to competitors.

## Best use cases

- Backend developers building on AWS (Lambda, EC2, S3, DynamoDB)
- Java/Python code migration and upgrades
- Generating AWS SDK boilerplate
- Security scanning of generated code

## Pricing breakdown

| Tier | Price | What you get |
|---|---|---|
| Free | $0 | Unlimited code suggestions, 50 chat queries/mo, 5 transformations/mo |
| Pro | $19/user/mo | Higher limits, advanced features, customization on your codebase |

## Beginner verdict

Great for Java backend developers (especially aiming at AWS roles, which is common in placement-track jobs). Free tier is enough to actually learn with.

- **Learning curve**: Easy to moderate
- **Setup required**: AWS Builder ID (free), install IDE extension
- **Gotchas**: Some features (transformation, customization) need Pro tier

## Alternatives

- [GitHub Copilot](github-copilot.md) — broader language coverage
- [Codeium](codeium.md) — better for non-AWS workflows
- [JetBrains AI Assistant](jetbrains-ai.md) — better IDE integration in IntelliJ

## Notes

Rebranded from "Amazon CodeWhisperer" in 2024. The "Q" name applies across AWS — Amazon Q Business is a different product for enterprise knowledge search.
