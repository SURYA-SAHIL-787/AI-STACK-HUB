## What it does

AI Studio is Google's developer playground for Gemini models. You can chat with Gemini in the browser, build prompts, and get an API key for free use in your code. The free tier offers some of the most generous rate limits in the industry — 15+ requests per minute for Gemini Flash, with no upfront billing.

## Best use cases

- Students learning to build with LLM APIs
- Personal projects that don't need enterprise compliance
- Prototyping before scaling to paid Vertex AI
- Multimodal applications (Gemini handles images, video, audio)

## Pricing breakdown

| Tier | Price | What you get |
|---|---|---|
| Free (AI Studio) | $0 | Rate-limited free access to all Gemini models |
| Vertex AI (paid) | Pay-per-token | Production tier with higher limits, enterprise features |

*Free tier is genuinely free with no credit card required.*

## Beginner verdict

For Java backend students, this is the cleanest starting point — free Gemini API access teaches you the patterns you'll use at enterprise jobs with AWS Bedrock or Azure OpenAI.

- **Learning curve**: Easy (web playground) → Moderate (API integration)
- **Setup required**: Google account + free API key
- **Gotchas**: Rate limits reset per minute; production apps need Vertex AI
