## What it does

ChatGPT has built-in data analysis ("Advanced Data Analysis," formerly Code Interpreter). Upload a CSV, Excel, JSON, or image of a chart — ChatGPT runs Python in a sandboxed environment to analyze, visualize, and predict. Free tier has limited daily uploads; Plus is much more generous.

## Best use cases

- ChatGPT users avoiding extra subscriptions
- Conversational data analysis
- One-off CSV processing
- Generating Python code while you watch (then copy for your own projects)
