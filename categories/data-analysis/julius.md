## What it does

Julius lets you upload a CSV, Excel file, or Google Sheet and chat with it. Ask "what's the average?", "show me a histogram", "predict next month's revenue" — Julius runs the analysis in Python under the hood and returns answers with code, tables, and charts. Effectively makes ChatGPT Code Interpreter accessible without ChatGPT Plus.

## Best use cases

- One-off data analysis tasks
- Students processing data for assignments
- Quickly visualizing CSV/Excel data
- Generating charts for reports without learning Matplotlib
