## What it does

Sourcetable looks like Excel but adds AI — generate formulas from natural language, auto-clean messy data, generate charts via prompts, and run AI analysis on selected ranges. Direct competitor to Rows with Excel-flavored UX.

## Best use cases

- Excel users wanting AI without switching to chat tools
- Cleaning messy CSV data with AI
- Generating complex formulas from descriptions
- Lightweight data analysis without leaving spreadsheet UI
