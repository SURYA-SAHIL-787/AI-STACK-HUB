## Quick comparison

| Need | Best pick |
|---|---|
| Comprehensive AI literature review | Elicit |
| Quick fact-check via science consensus | Consensus |
| Understanding a single paper deeply | SciSpace Copilot |
| Discovering related work visually | Connected Papers or Litmaps |
| Free academic search engine | Semantic Scholar |
| Citation context (does it support or contradict?) | Scite |

---

## For students writing papers

Start with **Elicit Free + Connected Papers + Semantic Scholar** — these three cover most undergraduate/early-grad research workflows at zero cost.
