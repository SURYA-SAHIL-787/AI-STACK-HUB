## What it does

Relume generates sitemaps from a description ("agency website for a SaaS startup"), then turns each page into wireframes built from their 1,000+ component library. Components export to Figma or Webflow as production-ready building blocks. Hugely popular with Webflow developers.

## Best use cases

- Website projects starting from scratch (sitemap + wireframes)
- Webflow developers using their component library
- Marketing teams building landing pages quickly
- Design agencies running multiple website projects

## Beginner verdict

If you build websites with Webflow or Framer, Relume's library alone justifies the price. For other workflows, simpler tools cover most needs.

- **Learning curve**: Moderate (lots of library to explore)
- **Setup required**: Paid account
- **Gotchas**: Best value tied to using Webflow — less value for other stacks
