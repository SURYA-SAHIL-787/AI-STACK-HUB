## What it does

AnythingLLM is an open-source app that turns any folder of documents into a searchable AI knowledge base. You can use it entirely locally (with a local LLM via Ollama) or connect to APIs (OpenAI, Anthropic, etc.). Drag in PDFs, transcripts, notes, code — then chat with them in the AnythingLLM interface.

## Best use cases

- Building a private "ChatPDF" that handles your entire document library
- Privacy-sensitive document chat (legal, medical, internal work)
- Pairing with Obsidian or Notion to add AI chat over your notes
- Learning how RAG (retrieval-augmented generation) works

## Beginner verdict

Not your first AI productivity tool, but the best free option if you value privacy. Pair with Ollama for fully local + free operation, or with OpenAI API for higher quality.

- **Learning curve**: Moderate (basic technical comfort needed)
- **Setup required**: Install desktop app + configure LLM connection
- **Gotchas**: Local LLMs need decent hardware; API usage costs money
