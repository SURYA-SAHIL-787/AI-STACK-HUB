## What it does

Tana combines outliner notes (like Roam/Logseq) with structured "supertags" that turn nodes into typed entities (tasks, books, people, meetings). AI features include summarization, transformation, and an "AI Search" that finds relevant nodes by meaning. The command-palette-driven UX feels more like a code editor than a notes app.

## Best use cases

- Power users who outgrew Roam/Logseq
- Structured personal CRM, task management, meeting notes all in one
- People who want a true "database + notes" hybrid with AI
- Workflow obsessives

## Beginner verdict

Not a starter tool. Worth exploring only if you've used Roam, Logseq, or Notion and want more power + AI. The learning curve is real.

- **Learning curve**: Steep
- **Setup required**: Paid account; tutorial commitment
- **Gotchas**: Workflow design takes weeks to settle; don't expect immediate productivity
