## What it does

Comet is Perplexity's desktop browser. Built around Perplexity's search/research style — every page can be queried, sidebar gives Perplexity-grade AI answers, can act as an agent that does multi-step tasks across sites (book a flight, summarize emails, gather data). Replaces Chrome/Edge if you're heavy on research/AI workflows.

## Best use cases

- Perplexity Pro users wanting full-browser integration
- Research-heavy work (academics, journalists, analysts)
- Agentic tasks across multiple websites
- Replacing default browser if Perplexity is your main AI tool

## Beginner verdict

Worth trying if you already pay for Perplexity Pro. If not, the free [Perplexity web app](../chatbots-general-ai/perplexity.md) covers most needs without needing a new browser.

- **Learning curve**: Easy
- **Setup required**: Download desktop app + Perplexity account
- **Gotchas**: Long-term browser commitment — try alongside your current browser first
