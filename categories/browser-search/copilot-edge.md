## What it does

Microsoft Copilot is built into the Edge browser's sidebar. Free features include page summarization, AI chat (GPT-4 powered), image generation via DALL-E 3, and "Compose" for drafting text. Tightly integrated with Microsoft's ecosystem — works inside Bing search results and Microsoft 365 apps.

## Best use cases

- Summarizing long documents/articles you're reading
- Drafting emails/text without leaving the browser
- Free DALL-E 3 image generation (Designer)
- Windows users wanting an integrated AI

## Pricing breakdown

| Tier | Price | What you get |
|---|---|---|
| Free Copilot | $0 | Sidebar chat (GPT-4), page summary, basic image gen |
| Microsoft 365 Copilot Pro | $20/mo | Higher limits, Copilot in Office apps |
| Microsoft 365 Copilot (Enterprise) | $30/user/mo | Full Copilot across Microsoft 365 + business data |

## Beginner verdict

If you use Edge on Windows, it's already there — try it. Quality is good and the page summarization is genuinely useful.

- **Learning curve**: Easy
- **Setup required**: Install Edge browser; sign in with Microsoft account
- **Gotchas**: Some features require signing in with a personal Microsoft account vs work account
