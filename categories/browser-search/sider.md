## What it does

Sider is a browser extension that adds an AI chat sidebar to any browser. Features include chat with multiple models (GPT, Claude, Gemini), page summarization, translation, AI image generation (Midjourney/DALL-E via Sider), and PDF chat. Browser-agnostic alternative to Edge Copilot or Brave Leo.

## Best use cases

- Chrome/Firefox users who want a Copilot-style sidebar
- Multi-model chat without switching tools
- Translation while browsing
- Quick page summaries in any browser
