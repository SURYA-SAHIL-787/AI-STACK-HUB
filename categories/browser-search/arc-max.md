## What it does

Arc Max adds AI features to the Arc Browser desktop: "Ask on Page" (AI Q&A about the current page), 5-second previews (AI summary on link hover), tidy tab titles (auto-renames long tabs), and "Ask ChatGPT in command bar." Originally bundled into Arc, may be free in some configurations now.

## Best use cases

- Existing Arc Browser users wanting AI features
- Cluttered tab managers (auto-rename helps)
- Quick page Q&A without opening separate chat windows
