# Autonomous Coding Agents

AI agents that take coding tasks end-to-end — read your codebase, plan changes, write code, run tests, iterate. Different from inline assistants (which suggest while you type) — these can complete entire tasks autonomously.

## Quick comparison

| Need | Best pick |
|---|---|
| Free CLI agent for terminal workflow | Aider |
| Free VS Code agent | Cline or Roo Code |
| Open-source Devin-style autonomous engineer | OpenHands |
| "Hire" an AI engineer for tasks | Devin |
| AI-first IDE with agent | Cursor or Windsurf |
| Generate a working web app UI | v0 or Bolt.new |
| Already pay for Cursor Pro | Cursor Composer |

---

## For Java backend students

Cursor + Cline are the most practical "agents" you'll actually use day-to-day. Devin is famous but expensive and aimed at production teams. For learning: install Cline (free) in VS Code with your free Google AI Studio API key — that's a powerful agent setup at zero cost.
