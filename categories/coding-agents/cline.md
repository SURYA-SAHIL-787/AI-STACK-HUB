## What it does

Cline (formerly Claude Dev) is a VS Code extension that adds Cursor-style agent capability. It can read your files, make multi-file edits, run terminal commands (with approval), and iterate on tasks. Bring your own API key (Anthropic, OpenAI, Google, OpenRouter, etc.). Free to install and use; you pay only for the underlying model API.

## Best use cases

- VS Code users avoiding Cursor's subscription
- Trying out agent workflows on a real codebase
- Anthropic API users who want IDE integration
- Backend devs writing/modifying API endpoints

## Pricing breakdown

| Tier | Price | Notes |
|---|---|---|
| Extension | Free | Install from VS Code marketplace |
| LLM API | Pay-per-token | Anthropic Claude Sonnet typical: ~$0.05–0.50 per task |

## Beginner verdict

Best free-to-install agent for VS Code. Pair with a Google AI Studio free Gemini key to start at literally $0 cost.
