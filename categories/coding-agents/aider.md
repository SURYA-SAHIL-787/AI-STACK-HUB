## What it does

Aider runs in your terminal and works directly on your git repo. You describe a task ("add a /healthz endpoint that returns OK") and it reads relevant files, makes edits across multiple files, auto-commits with descriptive messages. Bring your own API key (OpenAI, Anthropic, OpenRouter, Groq, etc.). One of the most-respected open-source coding agents.

## Best use cases

- Multi-file refactors guided by clear task descriptions
- Quick edits without leaving the terminal
- Backend devs who prefer CLI over IDE plugins
- Learning how coding agents work (open-source)

## Pricing breakdown

| Tier | Price | Notes |
|---|---|---|
| Aider itself | Free | Open-source Python tool |
| LLM API | Pay-per-token | Use cheap models like Groq Llama for free-ish runs |

## Beginner verdict

For Java backend students, Aider + free Groq API = the cheapest path to using a real coding agent. Excellent for learning agent patterns before paying for Devin/Cursor.
