## What it does

Roo Code (formerly Roo Cline) is a community fork of Cline that ships features faster and adds extras: custom modes (specialized agents for code review, architecture, planning), multi-LLM "team" support, more aggressive auto-approve options, and customization knobs Cline doesn't have. Same fundamental agent — different feature set.

## Best use cases

- Cline users who want bleeding-edge features
- Custom "modes" for specific workflows (e.g., architect mode that only plans, code mode that only implements)
- Teams comparing agent variations

## Pricing breakdown

| Tier | Price | Notes |
|---|---|---|

## Beginner verdict

If you start with Cline and find yourself wanting more knobs, try Roo Code. For new users, Cline's defaults are cleaner.
