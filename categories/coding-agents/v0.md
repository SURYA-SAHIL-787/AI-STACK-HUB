## What it does

v0 (by Vercel) generates React + Tailwind UIs from text or image prompts. Unlike static design tools, output is real production-quality React code (using shadcn/ui by default) you can copy into a Next.js project or deploy directly to Vercel. Now agentic — can build multi-page apps with backend logic.

## Best use cases

- Building MVPs without designing in Figma first
- Generating landing pages and marketing sites
- Frontend devs accelerating component creation
- Backend devs (you!) building UI for personal projects
