## What it does

Bolt.new (by StackBlitz) runs a full Node.js dev environment in your browser. Describe an app, and Bolt's AI agent generates the code, installs dependencies, runs it, shows preview, and iterates based on your feedback. Can deploy directly to Netlify. Different from v0 by being full-stack (frontend + backend + database) in one workflow.

## Best use cases

- Founders prototyping full apps in an hour
- Hackathon projects
- Personal full-stack experiments
- Backend devs experimenting with frontend frameworks

## Beginner verdict

For Java backend students, Bolt is a fun way to explore web stacks you don't use professionally (React, Vue, Svelte) without setting up local dev environments.
