## What it does

n8n is the leading open-source Zapier/Make alternative. Visual workflow builder you can run on your own server (free) or in their cloud. Strong on AI features — built-in LangChain integration, AI Agents node, can use any LLM. Popular for building agentic AI workflows that integrate with company tools.

## Best use cases

- Self-hosting automation for data privacy
- Building AI agents that take actions
- Developer-led automation projects
- Replacing Zapier at scale (no per-operation costs when self-hosted)

## Beginner verdict

Not your first automation tool. Start with Zapier/Make. Move to n8n when you want self-hosting, scale, or AI agent workflows.

- **Learning curve**: Moderate (cloud) / Steep (self-host)
- **Setup required**: Docker or npm for self-host; account for cloud
- **Gotchas**: Self-hosting requires server admin knowledge
