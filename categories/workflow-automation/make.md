## What it does

Make is Zapier's main competitor. Drag-and-drop visual canvas for building workflows, supports complex branching/iteration, integrates with 2,000+ apps. Free tier provides 1,000 operations/month — significantly more useful than Zapier's task-counting model. Recently added AI workflow generation.

## Best use cases

- Complex workflows with conditional logic
- Cost-effective automation at scale
- Webhook-based integrations
- E-commerce + marketing automation
