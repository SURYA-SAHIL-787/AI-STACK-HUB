## What it does

Pipedream lets developers build workflows that mix no-code triggers/actions with custom code steps (Node.js, Python, Go, Bash). Free tier includes a remarkable 100,000 workflow invocations/month, making it the most generous free option for actual production use.

## Best use cases

- Developers automating internal workflows
- Glue code between APIs that no-code can't handle
- Scheduled jobs (cron alternative) with code
- Building MVPs of automation features

## Beginner verdict

If you can write basic JavaScript or Python, Pipedream's free tier is incredible value. For pure no-code, stick with Zapier/Make.

- **Learning curve**: Moderate (developer skills help)
- **Setup required**: Free account
- **Gotchas**: Compute credit system on paid tiers — read pricing carefully
