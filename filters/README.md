# Filters

The same tools as [categories/](../categories/), sliced different ways for fast discovery.

---

## By Pricing

- `by-pricing/free.md` — fully free tools (no card required)
- `by-pricing/freemium.md` — free tier exists, paid tier unlocks more
- `by-pricing/paid.md` — paid-only tools

## By Skill Level

- `by-skill-level/beginner.md` — no setup, easy UI, gentle learning curve
- `by-skill-level/intermediate.md` — needs basic familiarity with the domain
- `by-skill-level/advanced.md` — power-user tools, often require technical setup

## By Role

- `by-role/students.md` — best picks for studying, note-taking, learning
- `by-role/developers.md` — coding assistants, debuggers, agents
- `by-role/designers.md` — image, mockup, UI design tools
- `by-role/writers.md` — drafting, editing, paraphrasing tools
- `by-role/researchers.md` — search, summarization, knowledge tools

---

*Filter pages are populated automatically as tools are added to categories. Empty filters will fill in over time.*
